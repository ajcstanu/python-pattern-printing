# 🔷 Python Pattern Printing

A collection of Python pattern printing programs using loops — 
covers stars, pyramids, diamonds, triangles, and number patterns.

---

## 📌 About

Pattern printing is a core concept in Python that tests your understanding of:
- Nested loops
- Loop control (range, conditions)
- String manipulation
- Logic building

This notebook covers 20+ pattern types with clean, well-commented code.

---

## 🗂️ Patterns Covered

| Category | Examples |
|---|---|
| ⭐ Star Patterns | Right triangle, Inverted triangle, Pyramid, Diamond |
| 🔢 Number Patterns | Floyd's triangle, Pascal's triangle, Number pyramid |
| 🔤 Alphabet Patterns | A-Z triangle, Character pyramid |
| 🔷 Mixed Patterns | Hourglass, Rhombus, Hollow patterns |

---

## 🛠️ Tech Stack

- **Language:** Python 🐍
- **Environment:** Jupyter Notebook
- **Concepts:** Nested loops, String formatting, Pattern logic
